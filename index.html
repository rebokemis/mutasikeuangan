Sinkronisasi Google Sheet

Seluruh rekap (termasuk Buku Kas & Laporan Bulanan) dikirim otomatis — 6 tab siap cetak A4 landscape.

📋 Cara menghubungkan ke Google Sheet (sekali saja)
  1. Buka sheets.new → buat spreadsheet baru, beri nama misal “Buku Kas Paguyuban Tirto Wening”.
  2. Menu Ekstensi → Apps Script → hapus semua isi editor, tempel Kode v4 di bawah, lalu simpan.
  3. Pilih fungsi ujiCoba pada dropdown lalu klik ▶ Run, izinkan akses. Pastikan 6 tab rekap terbentuk.
  4. Deploy → New deployment → tipe Web app → Execute as: Me, Who has access: Anyone → Deploy.
  5. Salin Web App URL (berakhiran /exec) → tempel di kolom atas → Simpan → 🔎 Tes Koneksi → ⇪ Kirim Sekarang.

Jika kode diedit: Deploy → Manage deployments → ✏️ → Version: New version → Deploy.

⚠ URL berfungsi seperti kata sandi — jangan dibagikan. Akses wajib “Anyone”.

❓ Masih gagal sinkron? Periksa satu per satu
  1. URL wajib berakhiran /exec (bukan /dev).
  2. Deployment: Execute as = Me, Who has access = Anyone.
  3. Setiap edit kode wajib deploy ulang versi baru.
  4. Jalankan ujiCoba dari editor — error merah di log menunjukkan sumber masalah.
  5. Jika muncul Failed to fetch / CORS, centang Mode Kompatibel.
